# Runbook для Codex

1. Прочитай `AGENTS.md`, `SPEC.md`, `PLAN.md`, `STATUS.md` и относящиеся к этапу разделы `docs/ARCHITECTURE.md`.
2. Проверь чистоту рабочей копии. Не перезаписывай пользовательские изменения и не исправляй несвязанные файлы.
3. Выполни только один запрошенный этап. Если обнаружена необходимая смена архитектуры, сначала зафиксируй решение в `docs/DECISIONS.md`.
4. Сначала добавь или обнови исполняемую проверку критерия, затем реализуй минимально достаточное решение.
5. После реализации запусти указанные в этапе lint, typecheck, unit/integration tests и сборку. Ошибки исправляй до перехода дальше.
6. Проверь diff на секреты, случайные generated-файлы, float для денег, отсутствие tenant-фильтра и утечки данных в логи/LLM.
7. Обнови `STATUS.md`: выполненное, команды и результаты проверок, решения, известные ограничения, следующий этап.
8. Если все критерии выполнены, создай один conventional commit с номером этапа. Не делай push и не начинай следующий этап без явного запроса.
9. Если внешний сервис или GPU недоступен, заверши всё, что можно проверить локально, добавь автоматизированный preflight/smoke-test и точно опиши непроверенную часть. Не объявляй её успешно проверенной.
